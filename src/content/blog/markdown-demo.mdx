# Rubrik (inte titel)

Detta inlägg visar alla Markdown-funktioner som stöds på Teklas. Använd detta som referens när du skriver nya inlägg.
Ovanför denna sektion finns metadata så som titel, beskrivning, publiceringsdatum, kategori (opinion-piece,cartoon,book-review,art) och heroImage (~ thumbnail för inlägget)

## Textformatering

Du kan skriva text på flera olika sätt:

- **Fet text** för att betona viktiga punkter
- *Kursiv text* för subtila betoningar
- ***Fet och kursiv text*** för maximal effekt
- ~~Genomstruken text~~ för att visa ändringar
- `Inline-kod` för kodreferenser i texten

### Kontrollera bildstorlek med HTML

Du kan använda HTML `<img>`-taggar för att kontrollera storlek:

**Liten bild (200px):**

<img src="/favicon.svg" alt="Liten bild" width="200" />

**Medelstor bild (400px):**

<img src="/favicon.svg" alt="Medelstor bild" width="400" />

**Stor bild (600px):**

<img src="/favicon.svg" alt="Stor bild" width="600" />

### Använda Astro Image-komponenten (i MDX)

I MDX-filer kan du importera och använda Astro's `<Image>`-komponent för mer kontroll:

```mdx
import { Image } from 'astro:assets';
import MinBild from '../assets/min-bild.png';

<Image src={MinBild} width={800} alt="Beskrivning" />
```

## Bildkarusell

För att visa flera bilder på ett interaktivt sätt kan du använda `Carousel`-komponenten. Den har en suddig bakgrundseffekt, navigeringsknappar och ett helskärmsläge.

import Carousel from '../../components/Carousel.tsx';
import LundagardStrip from '../../assets/images/lundagard-strip.png';
import NeaYlva from '../../assets/images/nea-ylva.png';

<Carousel
  client:load
  images={[
    { src: LundagardStrip.src, alt: 'Lundagård-serien' },
    { src: NeaYlva.src, alt: 'Nea och Ylva porträtt' },
    { src: LundagardStrip.src, alt: 'Lundagård-serien igen' }
  ]}
/>

### Hur man använder karusellen

1. Importera komponenten och bilder i början av ditt MDX-inlägg:
   ```mdx
   import Carousel from '../../components/Carousel.tsx';
   import Bild1 from '../../assets/bild1.png';
   import Bild2 from '../../assets/bild2.png';
   ```

2. Använd komponenten med en images-prop:
   ```mdx
   <Carousel
     client:load
     images={[
       { src: Bild1.src, alt: 'Beskrivning av bild 1' },
       { src: Bild2.src, alt: 'Beskrivning av bild 2' }
     ]}
   />
   ```

3. Bilder navigeras med pilknapparna eller punkterna längst ner.

4. Klicka på förstoringsikonen i övre högra hörnet för att visa i helskärm.
